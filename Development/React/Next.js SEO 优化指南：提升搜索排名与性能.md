## SEO 是什么？

**SEO（Search Engine Optimization，搜索引擎优化）** 是指通过技术手段和内容策略来提升网站在搜索引擎（如 Google、Bing、百度）中自然排名的一套方法论。它的核心目标很简单：**让用户搜到你，点进来，留下来**。

为什么 Next.js 天然适合 SEO ？

与传统的客户端渲染（CSR）React 应用不同，Next.js 支持服务端渲染（SSR）和静态生成（SSG），这使得搜索引擎爬虫可以直接获取到完整的 HTML 内容，而不是一个空壳的 JavaScript 应用。这意味着你的页面内容会被立即索引，大幅缩短了收录时间。

大幅缩短收录时间只是第一步，真正决定排名的是后续细节。幸运的是，Next.js 提供了一整套内建的 SEO 工具，帮助你把这些细节落实到位。以 Next.js 13+ 的 App Router 为例，它引入了强大的 Metadata API，你可以在 `layout.tsx` 或 `page.tsx` 中导出 `metadata` 对象，集中定义页面的标题、描述、关键词、Open Graph 和 Twitter Card 等标签。对于动态路由页面，还可以通过 `generateMetadata` 函数根据请求参数异步生成专属元数据，确保每个内容页都有独一无二的标题和摘要，避免因重复标签导致搜索引擎权重分散。

除此之外，性能是搜索引擎排名的重要因子，而 Next.js 在性能优化方面同样有独到优势。内置的 `next/image` 组件会自动进行图片压缩、响应式加载和懒加载，大幅降低页面体积并提升 Core Web Vitals 中的 LCP 指标；`next/script` 让你能够智能控制第三方脚本的加载时机，减少对首屏渲染的阻塞。再配合静态生成（SSG）或增量静态再生（ISR）策略，页面可以预渲染成 HTML 并以 CDN 形式快速分发，既减轻服务端压力，也显著提升访问速度。最后，别忘了生成并提交 `sitemap.xml` 和 `robots.txt`——Next.js 可以在项目结构中以约定方式动态生成这些文件，帮助搜索引擎更快地发现你的页面、了解站点层级，并精准控制哪些内容需要被索引。把这些能力组合起来，才能真正将 Next.js 的渲染优势转化为可持续的搜索排名提升。
